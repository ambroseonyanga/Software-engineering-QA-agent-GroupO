# Controlled Corpus Source Register

This record is the searchable text representation of `knowledge/source_register.csv`. It identifies the authorised sources available to the Software Engineering QA Agent retrieval pipeline.

- SRC-001: Project Charter. Defines the project problem, target users, objectives, scope, assumptions and constraints.
- SRC-002: User Stories and Acceptance Criteria. Defines user stories, requirements and acceptance criteria.
- SRC-003: AI Boundary Matrix. Defines AI responsibilities, deterministic responsibilities and human approval boundaries.
- SRC-004: Model Selection Note. Documents the selected model and model-selection considerations.
- SRC-005: Prompt Specification v1.0. Documents the initial QA agent prompt.
- SRC-006: Prompt Specification v1.1. Documents the revised QA agent prompt and traceability constraints.
- SRC-007: Prompt Evaluation. Records prompt evaluation cases, observed behaviour, weaknesses and improvements.
- SRC-008: Baseline Model Interaction. Records baseline Qwen3 model interaction and performance evidence.
- SRC-009: Week 1 Progress Report. Records Week 1 project progress, decisions and evidence.
- SRC-010: Week 2 Progress Report. Records Week 2 model integration, prompting and evaluation progress.
- SRC-011: BSE4104 Week 3 Context Engineering and RAG Requirements. Records the course Week 3 activities and deliverables.
- SRC-012: Week 3 Progress Record. Records the Group O Week 3 implementation status and completed deliverables.
- SRC-013: Controlled Corpus Source Register. Provides the searchable inventory of authorised corpus sources.
- SRC-014: Week 4 Tool Catalogue. Defines the Week 4 tool contracts, schemas, authorization and failure behaviour.
