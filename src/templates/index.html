Week 4 tools

The model can choose one approved tool. Drafts remain local. Test execution, publishing, merging and deployment are unavailable.

These calls go through the tool allow-list. Retrieval reads the project corpus. Issue notes are stored as local drafts only.

Week 5 bounded agent

Give one observed failure. The agent may retrieve project evidence and then save one local draft, within fixed limits. It cannot run tests, submit, merge or deploy. It stops and hands off to you when unsure.
